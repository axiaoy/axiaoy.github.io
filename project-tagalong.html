Tagalong Robot Builder & Library

Space Cookies Robotics · Co-Developer · 2024/25

  • Java
  • CLI tooling
  • Open source
  • Testing

Developed an open-source CLI tool that generates reusable Java robot subsystems from mechanism specifications, reducing boilerplate and saving critical development time during build season.

  • Integrated with WPILib robot projects and TagalongLib to generate configurable control code for mechanisms such as elevators, rollers, and pivots.
  • Built in per-robot configuration, unit tests, simulation support, and safety lockouts to improve reliability across competition and practice robots.
  • Enabled teams to begin command composition and robot-action development before hardware was fully operational.
  • Earned a regional Impact Award for contributions to the FRC community and open-source robotics tooling.
